# AIツール比較メモ

AIツールの料金とメモを一覧・比較するブラウザアプリです。サーバーやビルド環境は不要で、データはブラウザの localStorage に保存されます。

## ファイル構成

- `index.html`: 画面の骨組み
- `style.css`: レスポンシブ表示とダークモード対応のスタイル
- `script.js`: 追加・編集・削除・検索・並べ替え・localStorage保存・CSV出力・入力検証

## 起動方法

`index.html` を Chrome、Edge、Firefox、Safari などのブラウザで開いてください。ローカルサーバーを使う場合は、このフォルダで以下を実行し、`http://localhost:8000` を開きます。

```sh
python3 -m http.server 8000
```

## 主な機能

- 初期データ3件の表示
- ツールの追加・編集・削除
- 名前とメモでの検索
- 月額料金の昇順・降順ソート
- localStorageへの自動保存
- CSVダウンロード（UTF-8 BOM付き）
- 空欄・文字数・金額・重複名の入力検証
- CSVインジェクション対策
- スマートフォン向け表示、ダークモード対応

## データとプライバシー

データは利用中のブラウザの localStorage に保存され、アプリからサーバーには送信されません。ブラウザのデータを削除すると保存内容も消えるため、必要に応じてCSVをバックアップしてください。
